AI Learning Dashboard

Project Description

The AI Learning Dashboard is a single-page web application built to help aspiring AI and Data Science engineers track their learning progress. Developed using vanilla HTML, CSS, and JavaScript with no external frameworks or libraries, the entire project is self-contained in three files.

The dashboard features an interactive roadmap covering seven learning paths — Python, NumPy, Pandas, Data Visualization, Machine Learning, Deep Learning, and Generative AI — each with animated progress bars and completion status indicators. Four stat cards display overall progress, topics completed, learning streak, and finished projects at a glance.

A daily task manager allows users to add, complete, and track study tasks in real time. The AI Projects section showcases hands-on projects like House Price Prediction and Image Classifier, tagged with difficulty levels and technologies. A custom canvas-rendered bar chart visualizes weekly study hours without any charting library.

Additional pages include an editable profile and a settings page with toggleable preferences for dark mode, notifications, and progress reset.

The design uses a dark-themed aesthetic with the Inter typeface, glassmorphic elements, gradient accents, smooth animations, and micro-interactions. The layout is fully responsive, with the sidebar collapsing into a hamburger menu on mobile devices.
